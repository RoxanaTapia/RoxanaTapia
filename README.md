## Demos

**PDF Q&A.** Ask a question about a PDF and see the best-matching page next to the answer. If the document does not cover it, the app says so.

- Live: [ai-doc-pilot.roxanatapia.dev](https://ai-doc-pilot.roxanatapia.dev/try/website)
- Code: [ai-doc-to-chat-pipeline](https://github.com/RoxanaTapia/ai-doc-to-chat-pipeline)

**Receipt Intelligence.** Read a receipt, put a category on every line, and ask spending questions in plain language. Totals are calculated from the receipts, not guessed.

- Live: [receipt-intelligence.roxanatapia.dev](https://receipt-intelligence.roxanatapia.dev/try/website)
- Code: [receipt-intelligence-demo](https://github.com/RoxanaTapia/receipt-intelligence-demo)
- API: [receipt-intelligence-api](https://github.com/RoxanaTapia/receipt-intelligence-api)
- Workflows: [receipt-intelligence-n8n](https://github.com/RoxanaTapia/receipt-intelligence-n8n)

**Maple Street Front Desk.** A chat assistant for Maple Street Plumbing, a fictional plumbing business. It answers from the business's own pages, tells someone with an urgent problem to call, and never invents a price.

- Live: [front-desk.roxanatapia.dev](https://front-desk.roxanatapia.dev)
- Code: [maple-street-front-desk](https://github.com/RoxanaTapia/maple-street-front-desk)
